# CSE-428-1--2021-2-60-057 Project Repository

Welcome to the repository for the CSE-428 Section-1 project. This repository contains all the necessary files and documents related to the **UpCycle: Sustainable DIY & Recycling Guide** project.

## Repository Contents

- **`CSE428_Final_project_report.pdf`**: The comprehensive project report detailing the research, design process, and implementation of the UpCycle app.  
- **`CSE428_Final_project_presentation.pdf`**: The final presentation slides summarizing the objectives, methodology, and outcomes of the project.  
- **`Project-UpCycle_Lo-Fi.pdf`**: The low-fidelity prototype design showcasing the early interface layout and user flow of the UpCycle app.  
- **`Proposal_Presentation_UpCycle.pptx`**: The initial project proposal presentation outlining the problem statement, proposed solution, and design concept.  
- **`Recyclable and Household Waste Classification.ipynb`**: The Jupyter Notebook used for developing and testing the machine learning model for classifying recyclable and household waste.  
- **`UpCycle_Interface-Evaluation.docx`**: The document containing the usability and interface evaluation results of the UpCycle app.

## Project Overview

**UpCycle** is a sustainability-focused mobile application designed to encourage users to repurpose waste materials into creative, eco-friendly items. It promotes environmental awareness through DIY tutorials, recycling guides, and community sharing features.
